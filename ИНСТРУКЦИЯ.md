# Инструкция по работе с Telegram-ботом академической мобильности

Документ содержит две части: инструкцию для пользователя Telegram-бота и инструкцию для администратора веб-панели.

> Перед публикацией замените обозначения `<имя_бота>` и `<адрес_панели>` на фактические адреса вашей системы.

## 1. Инструкция для пользователя Telegram-бота

### Назначение бота

Бот предназначен для консультаций по вопросам академической мобильности. Пользователь может получить автоматический ответ от ИИ либо перейти к переписке с сотрудником.

### Начало работы

1. Откройте Telegram и найдите бота `<имя_бота>`.
2. Нажмите **«Запустить»** или отправьте команду `/start`.
3. Нажмите кнопку **«Отправить номер телефона»**.
4. Подтвердите отправку своего номера через Telegram.
5. После получения номера бот покажет меню выбора режима.

Телефон используется для идентификации обращения и отображается сотруднику в административной панели. Не отправляйте номер обычным текстом: используйте специальную кнопку Telegram.

### Режим ИИ

1. В главном меню нажмите **«Режим ИИ»**.
2. После сообщения «ИИ режим включён» напишите вопрос обычным текстом.
3. Дождитесь ответа. Формулируйте один понятный вопрос в одном сообщении и при необходимости уточняйте детали: вуз, страна, программа, сроки или вид мобильности.
4. Чтобы завершить консультацию, нажмите **«Выход»**. Бот вернет вас в главное меню.

Примеры вопросов:

- Какие документы нужны для участия в академической мобильности?
- Какие вузы являются партнерами?
- Каковы сроки подачи заявления?
- Как происходит перезачет дисциплин и кредитов ECTS?

Ответ ИИ носит консультационный характер. Важные сроки, требования и решения рекомендуется уточнять у ответственного сотрудника.

### Связь с сотрудником

1. В главном меню нажмите **«Связаться с сотрудником»**.
2. После сообщения о подключении напишите вопрос.
3. В этом режиме отправляйте только текстовые сообщения. Фотографии, документы, голосовые сообщения и другие вложения бот не принимает.
4. Ответ сотрудника появится непосредственно в чате с ботом.
5. Чтобы закончить диалог, нажмите **«Выход из режима общения с сотрудником»**.

Если сотрудник ответил, пока режим общения был выключен, сохраненные ответы будут доставлены при следующем подключении к сотруднику.

### Если возникла проблема

- Нет меню — отправьте `/start` и повторно передайте номер кнопкой.
- Бот просит отправлять только текст — замените вложение текстовым сообщением.
- ИИ долго не отвечает — подождите и повторите вопрос позднее либо выберите связь с сотрудником.
- Получено сообщение об ошибке ИИ — выйдите из режима, войдите снова и повторите запрос; если проблема сохраняется, обратитесь к сотруднику.
- Нет ответа сотрудника — обращение сохранено; дождитесь рабочего времени ответственного подразделения.

### Правила безопасного использования

- Не отправляйте пароли, банковские данные и иные секретные сведения.
- Передавайте только данные, необходимые для консультации.
- Не используйте бота для спама и сообщений, не относящихся к консультации.

## 2. Инструкция для администратора

### Вход в административную панель

1. Откройте `<адрес_панели>`.
2. Введите логин и пароль.
3. Нажмите кнопку входа.

Новая учетная запись может войти только после подтверждения администратором. Сессия входа действует до выхода из аккаунта или истечения срока авторизации.

В панели доступны разделы **«Профиль»**, **«Чат со студентом»**, **«Обучение ИИ»**, **«Диалоги с ИИ»** и **«Выход»**.

### Профиль и подтверждение учетных записей

В разделе **«Профиль»** отображаются логин, email и дата регистрации.

Чтобы изменить данные:

1. Нажмите **«Редактировать»**.
2. Измените логин и/или email.
3. Нажмите **«Сохранить»**.

В текущей версии сервер сохраняет только логин и email. Изменение пароля через это окно фактически не реализовано, даже если поле визуально доступно для редактирования.

Если имеются новые регистрации, ниже профиля появляется блок **«Заявки на регистрацию»**:

1. Проверьте логин и email заявителя.
2. Нажмите **«Подтвердить»** только для известного сотрудника.
3. После подтверждения пользователь сможет войти в панель.

### Переписка со студентами

1. Откройте **«Чат со студентом»**.
2. Выберите студента слева. Список содержит имя пользователя Telegram, телефон и последнее сообщение.
3. При необходимости воспользуйтесь поиском по имени или номеру телефона.
4. Проверьте статус в правой верхней части:
   - **«Доступен»** — студент сейчас находится в режиме общения с сотрудником;
   - **«Недоступен»** — этот режим у студента выключен.
5. Введите ответ и нажмите **«Отправить»**.

Если студент доступен, сообщение отправляется ему сразу. Если недоступен, ответ сохраняется и будет доставлен, когда студент снова включит режим связи с сотрудником.

Чтобы удалить переписку, нажмите значок корзины рядом с чатом и подтвердите действие. Удаление следует использовать осторожно: чат исчезает вместе с сохраненной историей и штатного восстановления в интерфейсе нет.

Рекомендации сотруднику:

- отвечайте кратко и однозначно;
- указывайте конкретные сроки, документы и контакты;
- не запрашивайте лишние персональные данные;
- перед отправкой убедитесь, что выбран нужный студент;
- не считайте статус «Недоступен» ошибкой — сообщение можно отправить, оно будет сохранено.

### Обучение ИИ документами

Раздел **«Обучение ИИ»** используется для добавления материалов, на основе которых формируются ответы.

1. Откройте раздел **«Обучение ИИ»**.
2. Перетащите файлы в область загрузки или нажмите на нее и выберите файлы.
3. Убедитесь, что нужные файлы появились в списке.
4. Нажмите **«Загрузить файлы»**.
5. Следите за индикатором обработки. Прогресс отображается по числу обработанных фрагментов («чанков»).
6. Дождитесь сообщения **«Обучение завершено»**.

Ограничение текущего интерфейса — не более 20 МБ на один файл. Проект обрабатывает документы PDF и DOCX; для предсказуемого результата рекомендуется использовать именно эти форматы. Загружайте текстовые документы хорошего качества: скан без распознанного текста может обрабатываться некорректно.

Ниже отображается таблица **«Загруженные документы»** с названием, размером и датой добавления. Чтобы исключить документ из базы:

1. Нажмите **«Удалить»** напротив документа.
2. Подтвердите удаление.

Во время обработки новых файлов кнопки удаления блокируются. Удаление документа удаляет также связанные с ним поисковые фрагменты, поэтому ИИ больше не сможет использовать этот материал.

Рекомендации по базе знаний:

- загружайте только утвержденные и актуальные версии документов;
- используйте понятные названия файлов;
- удаляйте устаревшие редакции перед добавлением новых;
- не загружайте документы с лишними персональными или конфиденциальными данными;
- после обновления задайте боту несколько контрольных вопросов и проверьте ответы.

### Просмотр диалогов с ИИ

1. Откройте **«Диалоги с ИИ»**.
2. Найдите пользователя через строку поиска.
3. Выберите диалог слева.
4. Просмотрите сообщения пользователя и ответы ИИ, сгруппированные по датам.

Раздел предназначен для контроля качества: выявляйте частые вопросы, ошибочные ответы и темы, по которым базе знаний не хватает материалов. Отвечать пользователю из этого раздела нельзя; для живой переписки используйте **«Чат со студентом»**.

### Выход из панели

Нажмите **«Выход»** в боковом меню. После завершения работы на общем компьютере всегда выходите из аккаунта и закрывайте браузер.

### Рекомендуемый рабочий порядок администратора

1. Проверить заявки на регистрацию и подтверждать только сотрудников.
2. Просмотреть новые обращения студентов.
3. Ответить на активные и ожидающие сообщения.
4. Проверить несколько последних диалогов с ИИ на качество ответов.
5. При необходимости обновить документы базы знаний.
6. Провести контрольное тестирование бота после обновления.
7. Завершить сеанс кнопкой **«Выход»**.

## 3. Краткая памятка

| Роль | Задача | Действие |
|---|---|---|
| Пользователь | Начать работу | `/start` → отправить контакт |
| Пользователь | Задать вопрос ИИ | **«Режим ИИ»** → написать вопрос |
| Пользователь | Обратиться к человеку | **«Связаться с сотрудником»** |
| Пользователь | Завершить режим ИИ | **«Выход»** |
| Пользователь | Завершить живой чат | **«Выход из режима общения с сотрудником»** |
| Администратор | Ответить студенту | **«Чат со студентом»** → выбрать чат → **«Отправить»** |
| Администратор | Обновить знания ИИ | **«Обучение ИИ»** → выбрать файлы → **«Загрузить файлы»** |
| Администратор | Проверить ответы ИИ | **«Диалоги с ИИ»** → выбрать пользователя |
| Администратор | Подтвердить сотрудника | **«Профиль»** → **«Заявки на регистрацию»** → **«Подтвердить»** |
